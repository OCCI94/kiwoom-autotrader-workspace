## MCP 서버 추가 질문

- 서버가 노출하는 도구 목록을 전부 확인했는가. 주문·쓰기 도구는 기본 비활성인가.
- 키는 클라이언트 설정에 평문으로 들어가는가. 가능하면 환경변수 참조로 바꾸고, 설정 파일 권한을 600으로 둔다.
- 서버가 제3자 프록시를 경유하는가(요청이 작성자의 서버를 지나는 구조). 지난다면 어떤 데이터가 지나는지 적는다.
- 도구 실행 자동 승인은 켜지 않는다.
