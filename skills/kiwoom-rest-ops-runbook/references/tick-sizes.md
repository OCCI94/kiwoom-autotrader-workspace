# 호가단위 (KRX 주권, 2023-01-25 통일 이후)

소스 `kiwoom_autotrader/trading/paper_experiment_inputs.py`의 `common_tick(price)`(2026-11-02 KRX 규정 대조 주석)와 일치함을 2026-11-03 확인했다. 규정 출처: https://regulation.krx.co.kr/contents/RGL/03/03020100/RGL03020100.jsp

| 가격 구간 (원) | 호가단위 (원) |
|---|---|
| 2,000 미만 | 1 |
| 2,000 이상 5,000 미만 | 5 |
| 5,000 이상 20,000 미만 | 10 |
| 20,000 이상 50,000 미만 | 50 |
| 50,000 이상 200,000 미만 | 100 |
| 200,000 이상 500,000 미만 | 500 |
| 500,000 이상 | 1,000 |

코스피·코스닥 공통. 경계값은 "이상"이 다음 단위다(예: 2,000원은 5원 단위).

## 예외 (확인 필요)

- ETF·ETN·ELW: 가격과 무관하게 5원 단위로 알려져 있음. EXP_ETF_B arm이 쓰는 ETF(069500, 229200 등)의 지정가는 5원 배수여야 한다. 소스에 별도 처리가 있는지 확인 필요.
- NXT 호가단위는 KRX와 다를 수 있음(모의투자는 KRX만이라 당장 무관).
- 지정가를 단위에 맞추지 않으면 주문이 거부된다. 반올림 방향은 매수는 내림, 매도는 올림이 보수적이다(소스의 실제 규칙 확인).
