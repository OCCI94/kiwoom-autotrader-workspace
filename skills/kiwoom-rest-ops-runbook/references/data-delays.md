# 외부 데이터 지연·제한 규칙

| 출처 | 규칙 | 근거 |
|---|---|---|
| 키움 ka10081 일봉 | 당일 봉은 장 마감 후 확정. 장중 호출은 미완성 봉 | 봇은 16:00 이후 수집 |
| 키움 ka10080 분봉 | 직전 분까지. 동시호가 중 분봉 없음 | |
| pykrx | 종목별 요청 사이 1초 지연 권고(과호출 시 KRX 차단). 투자자별 매매 최종치는 18:00 이후. 공매도 T+2. 외국인 보유 D-2 | https://github.com/sharebook-kr/pykrx (조사 노트) |
| OpenDART | `list_date_ex`로 접수 시각까지. `final=False`면 정정 공시 포함. 정정은 원 공시 날짜로 소급 누출 가능 | OpenDartReader (조사 노트) |
| KIS 공식 API (참고) | 토큰 재발급 1분 1회, 초당 제한 초과 시 `EGW00201`, 모의계좌는 더 낮은 한도 | koreainvestment/open-trading-api (조사 노트) |
| Toss 읽기 전용 갱신 | 슬롯 예산, HTTP 429 시 재시도 금지 | 이 프로젝트 관측 |
| Telegram 채널 수집 | 메시지 `published_at`과 `ingested_at`을 분리 저장. 삭제·편집된 메시지는 재수집 시 사라질 수 있음 | 야간 분류 규칙 |

원칙: 판단 시각 이후에 알 수 있었던 정보는 그 시각의 신호에 쓰지 않는다. 데이터마다 "이용 가능 시각"을 기록한다.
