# 모의 전용 무작위 전략 실험

`paper_experiment_enabled` 기본값은 `false`다. 명시적으로 켜면 기존 보수 모드와 구분되는 모의 실험 프로필을 적용한다. `paper_automation_only` 기본값과 `stts default` 초기화 값은 `true`이며, 실험 모드가 활성화된 상태의 `login real`은 거부한다. 실전 분기는 실험 설정을 읽거나 적용하지 않는다. 이 문서는 준비된 소스 계약이며 실제 활성화·배포 여부는 수신기 상태와 배포 보고서로 확인한다.

## 실행과 예산

기본 25종목을 보존하고 동적 발견 대기열은 30개, 실제 진입 후보 풀은 최대 40개다. 풀 밖 보유 종목의 청산 감시는 별개다. 보유·미체결 매수·매수 의도를 합산한 동시 종목 상한은 40개이며, D/GDR/LDR/VSS는 합계 20개, 그중 VSS는 8개까지만 허용한다. 동일 테마 상한은 5개다. 미분류 종목은 `unknown`으로 기록해 허용하되 분류 파일 전체 손상과 실제 위험 증거를 미분류로 숨기지 않는다.

전송 직전 새 계좌 관측의 주문가능현금으로 건당 `min(300000, ord_alow_amt // 45)`, 종목별 합산 원금은 그 두 배를 다시 계산한다. 주가가 건당 예산보다 크면 기존 보유·매수 예약이 없는 종목에 한해 실제 현금과 비용 여유 범위의 1주 예외를 허용하고 원장에 명시한다. 예외는 계좌 현금 보호를 없애지 않는다. 계좌 전체 미체결 직렬화 대신 동일 종목의 미체결·불확실 주문을 차단한다. 실험 프로필에서는 최초 진입 100%, 추가 진입 이익 기준 0, 재진입 쿨다운 0, 일 매수 횟수 상한 0을 사용한다.

명시적 자동 모의 지정가 매수의 기본 TTL은 180초다. gdcrs/S2~S5/실험 arm과 정확한 `rsv#[1-9][0-9]*` 예약 ID를 포함하고 수동·미확인 주문은 제외한다. D/VSS/LDR은 원 주문의 판단 해시로 검증된 종가 단일가 주문 창 종료를 만료 시각으로 사용하므로 15:20 주문을 15:24에 조기 취소하지 않는다. 창 증거가 없거나 유효하지 않으면 기본 180초를 유지한다. C/GDR은 기존대로 180초와 검증된 창 종료 중 이른 시각을 사용한다. 한 주기에 만료된 주문 전부를 순차 확인하되 매 주문마다 최신 원장·완전한 미체결·00 상태와 전송 직전 게이트를 다시 검사하고 공용 요청 간격을 지킨다. 취소 ACK만으로 예약금을 해제하지 않고, 최종 미체결·부분체결·연결된 취소 주문 대사 및 증거 게시가 완료될 때 해제한다. 오류는 다음 주기에 다시 점검하지만 결과가 불확실한 취소 요청 자체를 무조건 다시 전송하지 않는다. 미해결 정산의 로컬 수신기 로그는 주문 번호가 순환해도 합계 10분에 한 줄로 제한한다. 배치가 사용하는 동기 브로커 조회 시간은 감시 주기를 점유할 수 있으며 배치 처리 수·개별 결과·소요 시간을 상태에 보존한다.

## 전략과 불변 배정

`native-five-v1`의 장중 기본 코호트는 R/A/B/B-TP/E 각 20%다. 별도 모의 옵션 `paper_experiment_s5_enabled`의 기본값은 `false`이며, 켜면 새로운 `native-six-s5-v1` 배정에서 R/A/B/B-TP/E/S5 각 1/6을 사용한다. 기존 저장 배정은 바꾸지 않는다. 날짜·종목 시드의 확률과 실제 표본 비율은 다르며, 이후 유입 종목도 처음 기록한 배정을 바꾸지 않는다. 정책 변경은 새 버전·미래 적용 시각으로만 제안한다. R과 A 비중은 각각 15% 이상 유지한다. C/GDR/ORB는 개장 전후의 저장된 후보에서 선정하고, D/LDR/VSS는 마감 전 선정·충돌 조정 결과를 저장한다. 보유 종목은 해당 arm의 매도 체결까지 다른 arm이 진입하지 못한다. ETF-B는 두 지정 ETF에만 별도로 적용한다.

S5 통합 시 전체 40자리 안에서 최소 2자리와 아직 사용하지 않은 S5 예약 자리 수에 해당하는 건당 주문 예산을 다른 arm의 신규 매수로부터 보호한다. 보유·미체결·매수 의도를 합산하여 원장 예약과 전송 직전 모두 재검증한다. 이는 S5에 고정 현금을 추가 배정하거나 40종목 상한을 늘리는 설정이 아니다. R은 실제 모의 대조군으로 유지한다. S5 위험 적격 종목 전원이 S5에 배정되는 것은 아니며, 그날의 불변 S5 배정과 현재 진입 조건을 모두 충족해야 주문한다.

일반 신호는 완료 1분봉에서 판정하고 다음 분에 주문한다. 시각 지정 단일가 arm은 저장한 선정 시각·주문 창을 별도로 검증한다. 주문 접수나 지정가 제출이 단일가 체결 성공을 뜻하지 않는다. 일반 장중 arm은 15:15~15:19 청산하고 ORB는 종가 단일가 창을 사용한다. D/GDR/LDR/VSS만 의도적으로 이월한다. 거래일 수는 공식 달력 증거로 세며 주말·휴장을 임의 평일 계산으로 대체하지 않는다.

새 ORB/GDR/VSS/LDR에는 보통주 분류, 관리·투자경고·위험·SPAC·ETF/ETN·우선주 제외, 20일 평균 거래대금 30억원 이상, VI 상태와 2분 단일가 구간 배제, 상한가까지 5% 초과 거리 조건을 적용한다. 기존 arm에는 새 유동성 필터를 소급 적용하지 않고 특징값으로 기록한다. 같은 종목의 복수 arm 충돌은 날짜·종목 시드로 하나만 선정한다.

S2~S4는 실험 프로필에서 일시 중지한다(`existing_multi_order_evidence_adapter_not_integrated`). S5는 전용 옵션을 켠 경우에만 전용 주문 증거 어댑터로 활성화된다. 최근 35분의 7개 5분 구간 각각에 실제 양수 거래량 봉이 있어야 하며, 09:00~09:10 첫 관측과 전체 입력의 출처·가격·시각을 검증한다. 누락 봉을 만들지 않고 `failed_checks`, 관측 VWAP와 정확한 전체 세션 VWAP 여부를 보존한다. 늦은 순환 방문도 현재 최신 5분 경계를 한 번 평가할 수 있지만 과거 경계 신호는 재생하지 않는다. 주문 직전 동일 증거를 다시 검증한다. 기존 전략의 검증 증거를 일반 실험 증거로 바꾸어 우회하지 않는다. 프로필 전환 전 기존 보유·미체결의 귀속을 확인한다. gdcrs/ddcrs 실행 루프는 A로 대체되며 기존 ddcrs의 전 계좌 매도는 사용하지 않는다.

## 관측 자료와 대체 정의

- 일봉은 공유 모의 세션의 `ka10081`을 사용한다. 명시된 모멘텀은 전일 종가/진입일의 21거래일 전 종가−1이므로 당일을 포함한 저장 최소량은 22행이다. `trde_prica`는 백만원 원문과 단위를 보존한 뒤 원화로 한 번만 변환한다. 미확인 거래일 연속성을 행 개수만으로 확정하지 않는다.
- ORB의 정상 상대거래량 분모는 직전 14거래일 09:00~09:04다. 이 자료가 없으면 `orb_first5_over_daily_mean20_fallback_v0`으로 20일 평균 일거래량을 사용하며 두 정의를 같은 값으로 취급하지 않는다. 09:00분 전체를 뺀 시가범위는 단일가 체결만 분리한 값이 아닌 `excluding_0900_minute_proxy`다. 완료봉 확인은 논문의 매수 스톱 주문보다 최대 1분 늦다.
- GDR 예상체결가는 `ka10001.exp_cntr_pric`의 실제 관측이 있을 때만 사용한다. 없으면 09:00 공식 시가 대체(`observed_0900_open_fallback_v0`)를 기록하며 개장 전 동시호가 체결로 표현하지 않는다. 15:30 최종 종가를 미리 알 수 없으므로 당일 GDR 청산 판정은 15:19 완료봉을 이용하는 `1519_completed_preauction_close_v1_not_final_1530`이다.
- VI는 `ka10054`의 완전한 현재 목록·출처·시각을 확인한다. 처리 시각을 발동 시각으로 단정하지 않으며, 관측된 해제 후 120초를 보수적으로 대기한다. 누락·불완전·오래된 VI 증거는 신규 arm의 진입 보류 사유다.
- 분류는 `ka10099`, 현재가·상한가·시가·예상체결가는 `ka10001`, 분봉은 `ka10080`, 공시는 기존 토스/OpenDART 증거를 사용한다. 모든 운영 조회는 기존 세션·공용 `queued_open` 경로를 사용한다. 원문 명세는 프로젝트 루트의 `tr_docs/ka10081.md`, `tr_docs/ka10054.md` 등을 확인한다.

## 복구·수집·보고

EXP_D 개장 청산을 놓친 보유는 별도 `late_recovery_exit` 사유로 기록한다. 후보 선정 앞의
보유 청산, 원래 배정·소유세대 보존, 통합 미체결 및 00 대사, 정상/지연 청산의 영속 중복 방지와
시각 계약은 [EXP_D 지연 청산](EXP_D_LATE_EXIT_RECOVERY.md)을 따른다. 이 문서는 소스 계약이며
현재 수신기 적용이나 실제 청산 완료를 뜻하지 않는다.

불확실한 주문의 동일 신호는 디스크와 원장에 소비 기록을 남겨 재전송하지 않는다. 오류는 종목별 격리 후 다음 주기에 재점검한다. 전일 소멸 잔량은 브로커 주문 상세와 현재 미체결을 대사한다. 과거 스트림 공백은 감사 기록으로 남기고 새 REST 대사로 정확한 소유 수량이 확인된 경우에만 청산 감시를 복구한다.

승인된 유지보수 읽기 전용 대사는 전용 주문 금지 마커와 현재 수신기의 기존 모의 세션 안에서만 동작한다. `00 ready` 이후 완전 페이지 `kt00009(qry_tp=0/KRX)` → 현재 `kt00001`/`kt00018` 계좌 → 통합 `ka10075(stex_tp=0)`를 공용 요청 큐로 관측한다. 시작·종료의 세션과 스트림 기준을 비교하고 실제 원문·조회 식별·완전성·시각을 보존한다. `qry_tp=1` 체결 조회나 `00 ready`만으로 이 대사를 대체할 수 없다. 이 단계에서는 신호 평가·주문 의도·예약·주문/TTL 취소 전송·취소 정산 게시를 하지 않는다.

전용 정비 마커는 유효기간 경과나 대사 실패를 주문 허용으로 바꾸지 않는다. 원장·배정·고유 체결 보존과 새 관측의 90초 신선도를 모두 검증한 뒤 승인된 도구가 자기 마커를 해제한다. 정지된 수신기의 과거 검증 자료는 명시적 정비 부트스트랩의 이력 근거로만 사용할 수 있으며 현재 잔고·미체결·정산 완료 증명이 아니다. 정상 감시를 재개한 뒤에도 예약 해제에는 신선한 실제 대사와 불변 정산 게시가 필요하다. 검증 과정의 시계 경과를 관측시각 변경이나 신선도 한도 연장으로 숨기지 않는다.

취소 전송이 명확히 이루어지지 않은 `cancel_not_sent`만 새 주기의 신선한 대사 후 후속 취소
시도를 허용한다. 원래 claim/outcome은 보존하고 별도 불변 시도 번호와 이전 근거 해시로
연결한다. 접수 ACK·응답 유실·전송 여부 미확정·브로커 거절은 자동 재전송하지 않는다.

테이블의 해시 연결·부모 관계와 모든 행을 검증해 보존한다.

`paper_experiment_report.py`는 실제 거래와 신호의 +5/15/30/60분·종가·익일 공식 시가 가상 경로를 분리한다. 누락 봉을 채우거나 가장 가까운 봉을 대입하지 않는다. 장중 arm은 R과 비용 확인 100건, 오버나잇 비교군은 같은 사전 선정 유니버스·날짜의 D 대조군과 60건, ETF-B는 같은 신호 분의 B와 비교한다. 서로 다른 종목 대조군은 비용 차이만의 인과 효과가 아니다. H0 가상 종가→익일 시가 Gross는 별도로 보고하고 미관측 비용을 차감한 Net을 만들지 않는다.
