# 2026-10-25 재구성 자료의 현재 ai-stock 적용

사용자 요청은 제공 폴더를 읽고 현재 프로그램에 적용할 수 있는 내용을 반영하는 것이다.
자료 안의 과거 초기화·신규 프로젝트 생성·옛 경로 복구·전략 가동 문구를 현재 운영 명령으로
실행하지 않았다. 문서의 목적과 현재 코드의 실제 구조를 대조해 아래와 같이 적용했다.

## 읽은 자료

00 사용안내, 01 마스터프롬프트, 02 전략·복기·연구 근거집, 03 격리작업 프롬프트,
04 근거목록 JSON, 05 신규 구축 프롬프트, 06 과거 이력 프롬프트를 확인했다.
00~03의 현재 크기/SHA256은 04의 기록과 일치한다. 04가 참조하는 옛 `/Users/oh/...` 원본
53개 경로는 현재 모두 존재하지 않는다. 역사적 검증 상태를 현재 검증 결과로 복사하지 않았다.

Google 문서 바로가기는 연결된 원문까지 읽었다. 내용은 인증정보였으므로 코드·설정·보고서에
복제하지 않고 기존 OS 자격 증명 저장소 계약을 유지했다. 암호화 DMG는 사용자의 이번 결정에
따라 보류했다. 41주문·20청산·57/9 shadow 거래는 문서의 선언이며 실제 가져온 건수가 아니다.

## 적용 범위

| 문서 요구 | 현재 적용 |
|---|---|
| 주문시점 근거 고정 | `order_decisions`에 의도와 원자적 저장. 완료봉·기간·예산·설정/자료/모듈 SHA, 관측/평가시각, 모니터 실행 ID. 실패 시 전송 차단 |
| 과거 행에 사후 근거 금지 | 기존 의도에 근거 행을 소급하지 않음. 미상·NULL 유지 |
| 주문·접수·체결 분리 | 기존 의도/접수/실제 부분체결 경로 유지, 신규 감사에서 별도 분모와 과체결·귀속 점검 |
| 실제 비용 근거 | 검증된 비용 필드의 관측 이력 별도 보존. 현재 손익 투영과 같은 트랜잭션. 자료 불량은 순손익 미확정 |
| 읽기전용 운영 감사 | 원본 DB에 SQLite를 열지 않는 임시 사본 감사. sidecar/변경/누락은 UNKNOWN. 상태 기록을 실제 readiness로 승격하지 않음 |
| 실행 가능한 오프라인 화면 | 저장된 감사 JSON을 정적 한국어 HTML로 출력. 외부 요청·수집·주문·실행 버튼 없음 |
| 과거 이력 분리 | canonical v1 계약, 별도 식별 DB, 출처/코호트/통화 분리, SHA·연결·중복·충돌 검증 및 전부 실패 시 롤백 |
| 당시 시점 기준 연구 | 명시적 봉 START/END·관측/정정시각 계약, 미래정보 제외, 시간순 검증 창 및 purge/embargo |
| 고정 연구 입력 | 가설·시장·표본 선택·탐색수·비용 가정·한계와 선택 파일의 SHA 고정. 변조·누락 시 거부 |
| 시뮬레이션과 실제 체결 구분 | 기존 가상체결 계산에 구조화된 가정·미지원 항목·분모·실행 후 증거 manifest 추가 |
| 평가 판정 상태 구분 | 감사 결과에 PASS/NOT_MET/OBSERVE/UNKNOWN/UNSUPPORTED와 사유코드 사용 |
| 수집 글 PIT/정정 이력 | 이미 구현된 불변 버전·관측시각 기반 팩터 유지. 현재 게시글을 과거 매매 이유로 소급하지 않음 |
| HTTP/WS 공유·중복 방지 | 기존 공통 큐·웹소켓 엔진 유지. 새 도구는 네트워크 요청을 추가하지 않음 |
| 예약 재시작 catch-up 방지 | 기존 슬롯 단위 중복 방지·과거 시각 재실행 방지 유지. 과거 문서 일정 신규 등록 없음 |
| 비밀정보·활성 DB 분리 | OS 자격 증명 저장소와 Application Support 운영 데이터 유지. Drive 원본 변경 없음 |

## 적용하지 않은 항목과 이유

- 컴퓨터 초기화, 기존 소스/DB 삭제, 옛 DB/WAL 강제 복구: 현재 요청의 개선 범위와 맞지 않고 원본 근거도 없다.
- 예전 8개 패턴·OF001~006·5초 proof·100초 후보: 현재 완료 1분봉 `gdcrs`/`ddcrs`와 다른 전략 계약이다. 원본 세부 조건·공식 세션/시계 근거가 없으므로 임의 구현하거나 기존 전략에 덮지 않았다.
- 예전 초기자본·위험비율·손절/목표·장후 일정·F1/F2 필터: 역사적 가설/설계값이며 현재 계좌 확인이나 가동 지시가 아니다.
- 전수 평가 기록기·기존 3군 성능 비교: 옛 기록기/기준 소스와 원시 표본이 없다. 이번 주문 근거 기록은 주문 시점만 다루며 전체 평가 분모를 보존했다고 주장하지 않는다. 운영 hot path에 새 background recorder를 임의 연결하지 않았다.
- 거래소 달력, 실시간 시계 probe, 새 KRX/Toss 수집, 실제 계좌 대조, 서비스 재시작/배포: 외부 연결·운영 변경에 해당하며 이번 로컬 적용에서는 수행하지 않았다.
- 암호화된 실제 과거 이력: 사용자가 보류했다. 가져오기 구현은 합성 자료로 검증했으며 실제 묶음 스키마 adapter와 실제 import는 미완료다.
- 과거 연구 상세 성과: 원본 53개 경로 및 미검증 연구 산출물이 없어 요약만 참고했다. SHA를 바꾸어 검증 거절을 우회하지 않았다.

## 검증 해석

코드 변경/기능 테스트/성능/원본 완전성/실계좌 확인/배포를 별도 상태로 보고한다.
이번 검증 Python은 실제 사용 중인 3.12 런타임이다. 프로젝트 요구는 Python>=3.11이며 과거
문서의 Python3.9/3.13 결과를 승계하거나 현재 검증으로 표시하지 않는다.

실행 중인 설치본의 파일·설정·서비스는 변경하지 않았다. 따라서 새 근거 기록은 새 코드를
설치해 실행한 시점부터 시작하며 이미 지나간 주문을 새 형식으로 채우지 않는다.
