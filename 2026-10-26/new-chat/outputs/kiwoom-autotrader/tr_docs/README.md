# 키움 REST API 명세

기준 문서는 사용자가 제공한 `키움 REST API 문서.xlsx`입니다.
원본 위치: `/Users/tr-oh/Downloads/키움 REST API 문서.xlsx`.

특정 TR 명세를 요청받으면 해당 시트 전체와 참조 시트를 읽고 하나의 JSON 코드 블록으로 제공합니다.
사용법, 실전/모의 URL, HTTP 메서드, 요청/응답의 모든 헤더·바디, 필수 여부·형식·길이·단위·열거값,
연속조회, 성공·오류 조건, 요청/응답 예시와 유의 사항을 빠뜨리지 않습니다.
원문에 없는 항목은 임의로 채우지 않고 `null` 및 `문서 미기재`로 구분합니다.
문서 내용과 구현 선택 사항은 구분하며, 키나 토큰 예시는 실제 인증정보를 사용하지 않습니다.

현재 구현에서 사용하는 TR: au10001, ka10001, usa20100, ka10032, ka10099, kt10000, kt10001.
새 TR을 추가할 때 `api/`에 구현을, 이 폴더에 문서에서 확인한 명세 JSON을 둡니다.

저장된 상세 명세:

- [au10001.json](au10001.json): 접근토큰 발급. 원본 응답 예시와 쉼표만 보완한 교정본을 함께 보관합니다.
- [ka10001.json](ka10001.json): 주식기본정보요청. 전체 요청·응답 필드와 원문의 단위·예시 불일치를 구분합니다.
- [kt10000.json](kt10000.json): 주식 매수주문. 매매구분 20개, 원본 응답의 쉼표 누락, 주문번호 5자리 예시와 7자리 표 설명의 차이를 보관합니다.
- [kt10001.json](kt10001.json): 주식 매도주문. 매매구분 20개와 전체 요청·응답 필드 및 유효한 원본 예시를 보관합니다.

주문 명세의 IOC·FOK·GTP는 원문에 나온 이름만 기록합니다. 두 주문 시트에 없는 약어 정의,
거래소·모의/실전·장 시간별 지원 여부, 조건단가 연계 조건은 `문서 미기재`로 남깁니다.

각 JSON의 `source_cells`에는 해당 시트 사용 범위의 모든 셀 값을 보관하고,
`coverage`에는 필드·셀 개수를 기록합니다. 원문에 없는 형식·시간대·오류 조건은
`null`과 `문서 미기재`로 표시하며 구현 선택 사항과 분리합니다.
