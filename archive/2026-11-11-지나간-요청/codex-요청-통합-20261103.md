- 상장폐지 종목도 포함해 생존편향을 피해라. 마지막 20% 기간은 봉인 홀드아웃이다.
- 결론: "다음 날 기대값이 비용을 넘는 채널·유형이 있는가". 없으면 없다고 쓰고, 그래도 B-1은 "정보 제공"으로 만든다.

### B-1. 야간 추출 작업

- 범위: 전 거래일 15:30 ~ 실행 시각(KST)의 게시물. `edited_at`이 있으면 최신 버전을 쓰되 원본 해시를 같이 기록한다.

- 종목별 집계:
  1. 언급 수, 언급한 채널 수(서로 다른 채널), 첫 언급 시각과 마지막 언급 시각(KST)
  2. 전달·복붙 중복 제거: 같은 본문 해시가 여러 채널에 있으면 1건으로 세고 "전파"로 표시
  3. 입장과 촉매(B-2의 2·3단계). 악재·정정이 하나라도 있으면 별도 표시
  4. 언급이 **가격보다 앞섰는지**: 당일 분봉으로 첫 언급 시각 이후 30분 수익률과 그 이전 30분 수익률을 비교한다. 이미 오른 뒤의 언급은 "후행"으로 표시
  5. 채널 신뢰도 점수(B-0)를 가중치로 곱한다

### B-2. 분류 설계
현재 추출기의 분류는 한 덩어리라 어디서 틀리는지 알 수 없다. 11-03 11:26 실행 기준 7일치 언급 4,812건 중 종목 미확정 1,713·대상 불명 918·다종목 요약 859·짧은 이름 270이 버려졌고, 입장은 거의 "불명", 공시 검증은 전부 "미확인"이다. 아래 여섯 단계로 나누고 **단계마다 정확도를 따로 잰다.** 각 단계는 독립 모듈·독립 테스트로 만들어라.

0. **메시지 유형**: 뉴스 전달 / 공시 요약 / 종목 추천 / 시황·지수 / 특징주 목록(다종목) / 리포트 요약 / 광고·잡담. 유형별 처리 규칙을 둔다. **다종목 요약은 버리지 말고 줄 단위("종목명(등락률) 이유")로 쪼개서** 종목별 언급으로 살려라. 광고·잡담은 여기서 제외한다.
1. **종목 식별**: 우선순위 코드 > 고유한 전체 이름 > 별칭 + 업종 문맥. 두 글자 이름과 일반 단어와 겹치는 이름은 코드나 업종 문맥이 함께 있을 때만 인정한다. 채널별 사전 확률을 둔다(한국 특징주 채널의 "현대차"는 현대차, 미국 채널의 "테슬라"는 후보 아님). 못 찾은 문자열은 주 단위로 모아 별칭 사전 후보로 보고한다. 목표: 미확정 비율 60% → 25% 미만.
2. **입장(종목별 언급 단위)**: 호재 / 악재 / 중립 정보 / 추천·목표가 / 정정·취소 / 단순 나열. 키워드 사전으로 먼저 분류하고, 애매한 것만 야간에 LLM으로 재판정한다. LLM 판정은 야간 연구·후보 선별에만 쓰고 장중 주문 경로에는 넣지 않는다. 판정에 쓴 모델명·프롬프트 해시·입력 해시를 기록해 재현 가능하게 한다.
3. **촉매 유형**: 수주·공급계약(당일~수일) / 실적(당일) / 임상·허가·특허(당일~수주) / 지분·M&A·자사주(수일) / 증자·CB·감자(음성) / 정책·규제(수일) / 수급·차트(약함) / 루머·미확인(신뢰 낮음). 유형마다 기대 반응 기간을 같이 기록한다.
4. **검증 등급**: A = DART 공시와 제목·시각이 맞음(봇이 모으는 공시와 대조), B = 전달 중복 제거 후 독립 채널 2곳 이상, C = 단일 출처, D = 루머. 지금의 "미확인" 단일 값을 이 네 등급으로 바꾼다.
5. **시의성**: 첫 언급 시각 전후 30분 수익률로 선행·동시·후행 표시. 장후 언급은 다음 날 시가 반응으로 본다. 첫 언급 뒤 몇 시간 안에 언급 채널 수가 늘면 "확산 중"으로 표시한다.
6. **점수**: 종목·일자별로 채널 신뢰도(B-0) × 입장 × 검증 등급 × 선행 여부를 곱해 더한다. 가중치는 설정 파일에 두고 값과 근거를 메시지에 공개한다.

**정답 세트와 측정**
- 최근 7일 메시지에서 유형별로 고르게 300건을 뽑아 라벨링 파일(`telegram-nightly/gold/labels-v1.jsonl`)을 만들어라. 라벨은 0·1·2·3단계 결과다. 네가 초안을 채우고 "검토 필요" 표시를 붙여 나에게 넘겨라. 내가 수정하면 그것이 정답 세트다.
- 매주 정답 세트로 단계별 정밀도·재현율을 재고 주간 요약에 넣어라. 정답 세트는 분류 규칙을 고칠 때 쓰되, 규칙을 정답 세트에 맞춰 과최적화하지 않도록 절반은 봉인해라.
- 장중 추출기의 기존 피드 계약(`telegram-watch-candidates-v1`)은 바꾸지 마라. 새 분류는 야간 결과와 연구 보고에만 쓰고, 장중 피드에 반영할지는 정확도 측정 뒤 따로 결정한다.
