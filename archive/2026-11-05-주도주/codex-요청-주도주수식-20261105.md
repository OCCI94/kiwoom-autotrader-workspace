====================================================================
[1. 1부] 집중투자·CAPM·주가분해·4대 팩터(16지표)·생애주기·보조 시장지표  → Tier 3 (16지표 후행분은 Tier 2)
====================================================================
(1) 포트폴리오 종목 기여도 및 전체 수익률
  - `contribution_i = initial_weight_i * return_i`, 동일 비중 `initial_weight_i = 1 / K`
  - `R_p = sum(initial_weight_i * return_i)`
  - 테스트 기대값: +200% 종목 1개·나머지 0%일 때 K=3~5 → 40~66.67%p, +220% → 44~73.33%p, K=100 → 2%p / 2.2%p. 원문 입력문의 "33~66%"는 이 계산과 맞지 않으므로(원문 편집 주석) 기대값에 넣지 않는다.
(2) CAPM 및 주가 리레이팅 항등식
  - `E_R_i = R_f + beta_i * (E_R_m - R_f)`
  - `Price = EPS * PER`, `price_return = (1 + eps_growth) * (1 + per_change) - 1` (예: 1.2 × 1.25 = 1.5)
(3) 실적 가속도 및 영업 레버리지
  - 실적 가속도: `eps_qoq_t > 0.25 and (eps_qoq_t - eps_qoq_prev) > 0`. `eps_qoq`의 분모는 `abs(EPS_prev)`, 0 근처면 `None` (공통 규칙 3).
  - `OP_t = Sales_t * OPM_t`, `op_growth = (1 + sales_growth) * (OPM_t / OPM_0) - 1`. 마진 변화는 `%p = OPM_t - OPM_0`과 상대 변화율 `OPM_t / OPM_0 - 1`을 모두 반환. 테스트: 100→130, 10%→15% → +95%, +5%p, 상대 +50%.
(4) 4대 팩터 × 4개 하위 지표 = 16개 지표
  각 함수에 입력 가용성 태그를 붙인다: `[LOCAL_AFTER_COLLECT]`(DART 수집 후) 또는 `[NO_SOURCE]`(컨센서스·선행 추정치 없음 → 시그니처와 합성 데이터 테스트만).
  - 가치(V):
    1) `earnings_yield = eps / price = 1 / per` [LOCAL_AFTER_COLLECT] — 적자면 음수 그대로 반환
    2) `dividend_yield = dps / price` [LOCAL_AFTER_COLLECT]
    3) `book_to_market = book_equity / market_cap = 1 / pbr` [LOCAL_AFTER_COLLECT] — `book_equity <= 0`이면 `None`
    4) `cashflow_yield = cashflow / market_cap` [LOCAL_AFTER_COLLECT] — 기본 OCF, FCF는 옵션 (ASSUMPTION: 원문은 "일관성 필요"만 언급)
  - 성장(G):
    5) `fwd_sales_growth` [NO_SOURCE]
    6) `fwd_opm_change_pp = fwd_opm_t - fwd_opm_prev` [NO_SOURCE]
    7) `fwd_eps_growth` [NO_SOURCE] — 희석·순주식수 변화 반영
    8) `long_term_growth = reinvestment_rate * roic` [LOCAL_AFTER_COLLECT]
  - 모멘텀(M):
    9) `eps_revision_1m = (fwd_eps_t - fwd_eps_1m_ago) / abs(fwd_eps_1m_ago)` [NO_SOURCE]
    10) `ret_1m`, `ret_3m` [LOCAL] (수정주가 수집 후)
    11) `ret_6m`, `ret_12m` [LOCAL]
    12) `foreign_ownership_change_3m_pp = foreign_own_t - foreign_own_3m_ago` [LOCAL_AFTER_COLLECT] — 현재 로컬 이력은 33일뿐
  - 퀄리티(Q):
    13) `opm = operating_profit / sales` [LOCAL_AFTER_COLLECT] — 원문은 12M 선행 기준, 후행 대체는 ASSUMPTION
    14) `roe = net_income / equity` (`equity <= 0` → `None`) 및 듀퐁 3분해 `(NI/Sales) * (Sales/Assets) * (Assets/Equity)` [LOCAL_AFTER_COLLECT]
    15) `roic = noplat / invested_capital`, `roic_spread = roic - wacc` [LOCAL_AFTER_COLLECT]
    16) 재무 건전성 `equity_to_liabilities = equity / total_liabilities` = 1/부채비율(부채총계/자본총계). 변수명에 `total_debt`(이자부부채)를 쓰지 않는다. [LOCAL_AFTER_COLLECT]
(5) 주도주 생애주기 4단계 분류기 (`classify_lifecycle`)
  - 입력: V·G·M·Q 백분위, `eps_revision_1m`, 외국인 지분율 변화. 출력: 태동기 / 점화기 / 본격 상승기 / 성숙·교체기.
  - 원문은 정성 표만 제시하고 임계값이 없다. 임계값은 함수 인자로 받고 기본값(예: 상위권 = 백분위 ≥ 70, 약세 = ≤ 40)은 모두 ASSUMPTION으로 태그.
  - 태동기: V·Q 상위권, G·M 약세 / 점화기: `eps_revision_1m > 0`, 외국인 지분율 상승 시작, V 아직 상위권 / 본격 상승기: G·M 최상위, V 하락 허용 / 성숙·교체기: `eps_revision_1m <= 0`, M 둔화, 수급 정체.
(6) 시장 환경 보조 3지표 (원문에 산식 없음 → 전부 ASSUMPTION)
  - 수익률 분산: 동일 기간 종목별 수익률의 표준편차와 사분위 범위 둘 다 반환
  - 밸류에이션 스프레드: 고평가군·저평가군(상·하위 20%, ASSUMPTION)의 B/P 중앙값 격차
  - 순위 모멘텀 지속성: 최근 W주 동안 상위 X% 유지 비율 (W·X 인자, ASSUMPTION)

[2. 2부] 섹터 ETF 3대 신호·공통 백분위·국내 COMP 모델  → Tier 1

(1) 섹터 ETF 3대 신호 판정 및 행동 매핑 (`evaluate_sector_etf`) — 섹터 ETF 일봉은 로컬에 없음 [NO_SOURCE_YET]

  - 유동성·수급 긍정: 최근 1~2주 평균 거래대금 / 비교 기준 창 평균 `>= 1.20` 이고 외국인·기관 순매수가 1~2주 지속. 비교 기준 창 길이(직전 4주 기본)는 원문에 없으므로 ASSUMPTION 인자. AUM 순유입 분리 `net_inflow = delta_AUM - price_effect` 포함.
  - 행동 매핑: 3개 긍정=`ACTIVE_BUY`, 2개 긍정+1개 중립=`SMALL_START`, 1개 긍정=`WATCH`, 모두 부정=`EXCLUDE`
(2) 백분위 변환 함수 (`percent_rank`)
  - `book_formula` 모드: `(N - rank) / N * 100` (1위 = `(N-1)/N*100`)
  - `endpoint_adjusted` 모드(기본): `(N - rank) / (N - 1) * 100` (1위 100.0, 꼴찌 0.0)
  - 동점 `average`(기본)/`min`, 역방향 지표 부호 반전, 결측 제외 후 유효 N 산정, `N < 2` → `None`
(3) 국내 COMP 스코어 및 국면별 가중치
  - 기본식(중립): `COMP = 0.40 * rank_mom + 0.30 * smart_money + 0.20 * price_mom + 0.10 * valuation`
    * `rank_mom`: 4·12·25·52주 수익률 백분위의 평균을 다시 백분위화. 순위 분산 패널티(`mean - k * std`)는 옵션 인자 `rank_dispersion_penalty`(기본 0, ASSUMPTION)로만 두고, 켠 결과와 끈 결과를 둘 다 보고(2차 점검: 패널티가 신규 돌파 종목과 꺾이는 종목을 같은 점수로 만든다).
    * `smart_money`: 20거래일 기관+외국인 순매수 **금액**(시총 대비) 백분위 0.7 + 외국인 보유비율 **수준** 백분위 0.3 (분할 0.7/0.3은 ASSUMPTION; 원문은 두 입력만 명시). 현재 로컬 수급은 수량 기준 33일 → 수집 전엔 구조 검증만.
    * `price_mom`: 5·20·60거래일 수익률 백분위 + `close / high_52w` 백분위의 평균
    * `valuation`: ROE(`equity <= 0` → 0점), 이익수익률, 전년 동기 대비 영업이익 성장률(분모 `abs`) 백분위 평균. 원문은 선행 PER이나 컨센서스가 없으므로 후행 EPS 사용(ASSUMPTION `trailing_substitute`).
  - `COMP_REGIME_WEIGHTS` (SOURCE 부록 3 표 56): `neutral (0.40,0.30,0.20,0.10)`, `growth_bull (0.45,0.30,0.20,0.05)`, `high_rate_value (0.35,0.25,0.15,0.25)`, `post_crash (0.30,0.35,0.15,0.20)`. 국면 판정 로직은 만들지 않는다(원문 미공개). 국면은 인자로만 받는다.
  - COMP 등급: `>= 90` 강력매수(예시 비중 15~20%), `80~<90` 매수, `65~<80` 보유, `< 65` 매도 검토
  - 유니버스·포트폴리오 필터: 시총 `>= 300억`, 일평균 거래대금 `>= 10억`, 상위 10~15종목, 동일 산업 최대 3종목, 주간 점검 / 4~6주(기본 6주) 정기 교체. 점수와 함께 계산일·유니버스·데이터 기준일을 기록.

[3. 3부] 한국형 F-스코어·F 복합점수·교차검증·자본배분·가치평가·손익비·병렬 매도  → F·매도·손익비 Tier 1, 자본배분·가치평가 Tier 2
====================================================================
(1) 한국형 F 원점수 (`compute_korean_f_score`, TTM·공시 PIT 기준)
  - PIT: `disclosure_available_at <= as_of_date` 위반 시 즉시 예외. `available_at` = 접수일, 장 마감 후 접수면 다음 거래일. 정정공시는 원본 값을 이력으로 보존.
  - 금융업 `excluded_financial=True` → `None`.
  - 누적 공시값은 분기로 변환(4분기 = 연간 − 3분기 누적, 영업현금흐름 포함) 후 최근 4분기 합산 = TTM. 전년 TTM(t−4)과 비교.
  - 공통 4항목 `F_core ∈ {0..4}` — 각 항목 불리언을 `items = {sales, gpm, sga, ato}`로 함께 반환(매도 규칙의 F 4→3 사유 판정에 필요):
    1) `ttm_sales_t > ttm_sales_t_minus_4`
    2) `ttm_gpm_t > ttm_gpm_t_minus_4`, `GPM = (매출 - 매출원가) / 매출`, `delta_gpm_pp = gpm_t - gpm_t_minus_4`
    3) `ttm_sga_ratio_t < ttm_sga_ratio_t_minus_4`, `SGA_ratio = 판관비 / 매출`
    4) `ttm_asset_turnover_t > ttm_asset_turnover_t_minus_4`, `ATO = 매출 / 총자산` (기말 기본, 기초·기말 평균 옵션 — 기본값은 ASSUMPTION)
    동일(`==`)은 0점.
  - 소재 업종 발생액: `accrual_ok = (ttm_operating_profit_t - ttm_operating_cashflow_t < 0)`를 **별도 플래그**로 반환. `F_core`에 더하거나 `/5`로 정규화하지 않는다. (원문은 4점·5점 비교 방식을 정하지 않았음. 이 분리는 ASSUMPTION.) 원문 참조용 `f_raw_book`(일반 0~4, 소재 0~5)은 보고용 필드로만 두고 판정에 쓰지 않는다.
  - 매출원가가 없는(성격별 손익계산서) 기업은 `F_core = None`.
(2) F 복합점수 및 국면별 가중치
  - 기본식: `F_comp = 0.40 * P(F_core) + 0.30 * P(ret_1m) + 0.20 * P(ret_3m) + 0.10 * P(delta_gpm_pp)`
