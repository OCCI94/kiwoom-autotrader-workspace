# 주도주 수식 점검 2차 — "완전판" 코덱스 프롬프트 (2026-11-05)

대상: 1~5부·부록 1~4·대조표 전체 수식(10개 묶음)을 담은 완전판 프롬프트.
방법: 1차 점검([ai-stock-점검-20261105-주도주수식.md](ai-stock-점검-20261105-주도주수식.md))과 같은 방식. docx 원문의 1부·4부·5부·부록 1을 추가로 대조하고, 새로 들어온 예시 숫자는 전부 검산했다.

## 결론

- **새로 추가된 수식의 산술은 전부 맞다.** DCF(447.70 → 1,556.04 → 14.56), 영업 레버리지 95%, 역발상 8.75점, 금리차 47bp, 순유동성 5.83조, 자사주 26.3158%, 애플 로그 분해 1/3 — 원문 예시를 모두 재현한다.
- **1차에서 "구현하면 틀린 값이 나온다"고 한 4건은 하나도 고쳐지지 않았다.** 음수 기준 성장률, 자본잠식 ROE, 50% 축소 반복, 소재 4점/5점 혼용이 그대로 들어 있다.
- **데이터 주장도 그대로다.** "기존 ai-stock 보유 DART 재무·수급·섹터"는 어제 확인한 대로 존재하지 않는다(재무제표 없음, 일봉 비수정, 수급 33일).
- **범위가 5배 커졌는데 실제 값이 나올 수 있는 건 소수다.** 60여 개 함수 중 선행 추정치 계열(성장 4개·이익 모멘텀·선행 PER·선행 OPM)과 거시 시계열(연준 자산·TGA·RRP·2y/10y·DXY)은 데이터 소스 자체가 없다. 합성 데이터 단위 테스트는 통과하겠지만 그 이상은 아니다.
- **원문이 "산식 미공개·임의 추가 금지"라고 못 박은 항목에 프롬프트가 산식을 넣었다.** 생애주기 임계값, 시장 환경 3지표, 2×2 교차 임계값, 역발상 경계 방향 등. 1차에서 넣었던 SOURCE/ASSUMPTION 태그가 사라져서 나중에 "책의 규칙"과 "코덱스가 정한 규칙"을 구분할 수 없게 된다.

권고는 5절: Tier 1(운영 연결)·Tier 2(DART 수집 후)·Tier 3(순수 함수만)으로 나눠 지시하고, 6절의 보정 블록을 프롬프트 맨 앞에 붙인다.

## 1. 1차 지적 반영 여부

| 1차 지적 | 완전판 상태 | 판정 |
|---|---|---|

| F 3 + COMP ≥ 80 관찰 | 반영 | 반영 |

## 3. 구현하면 틀리거나 비는 새 항목

### 3-1. 금리곡선 4국면 분류기는 절반을 분류하지 못한다

프롬프트 조건(두 금리 부호가 같고 크기 비교)으로는 단기·장기가 반대로 움직이는 경우(twist), 한쪽이 0인 경우, 같은 폭인 경우가 모두 미분류다.

| dy_2y | dy_10y | 프롬프트 결과 |
|---|---|---|
| −20 | −10 | bull_steepening ✔ |
| −10 | +10 | **미분류** (스프레드 +20bp 확대) |
| +10 | −10 | **미분류** (−20bp 축소) |
| 0 | +10 | **미분류** |
| +10 | +10 | **미분류** (평행 이동) |

수정: `Δspread = dy_10y − dy_2y`로 steepening/flattening, `dy_2y + dy_10y`(또는 평균) 부호로 bull/bear를 정하면 전 영역이 분류된다. 둘 다 0이면 `parallel`/`unchanged`. 원문(1459~1473행)은 네 경우만 설명하므로 twist 명명은 ASSUMPTION.

### 3-2. 등급 비중 S6/A4/B3/C2는 30종목에서 100%가 안 된다

예: S3·A10·B10·C7 → 102%, S10·A20 → 140%. 원문도 "합계 조정·현금 처리 방식 미공개"(1193행). 프롬프트의 정규화/현금 모드 병행은 맞지만, 두 모드는 성과가 다르므로 백테스트 표에 모드를 반드시 기록하고 "합 < 100%면 현금, > 100%면 정규화" 같은 비대칭 규칙은 피할 것.

### 3-3. 변수 정의가 원문과 어긋나는 곳

| 항목 | 프롬프트 | 원문 | 문제 |
|---|---|---|---|
| 재무 건전성 | `equity / total_debt = 1/debt_ratio` | "Equity/Debt, 부채비율의 역수"(295행) | 한국 부채비율 = **부채총계**/자본총계. `total_debt`(이자부부채)로 구현하면 역수가 아님. 변수명을 `total_liabilities`로 |
| 실적 가속도 | `eps_qoq > 0.25 and Δqoq > 0` | 원문도 전분기 대비(93행) | 일치. 단 EPS 음수·0 근처에서 1차 §1-1과 같은 부호 문제. abs 분모 + 결측 처리 |
| 현금흐름 비율 | "OCF 또는 FCF 명시" | "어떤 현금흐름을 쓰는지 일관성 필요"(200행) | 하나로 고정(ASSUMPTION) |
| 샤프 비율 | 부록 1 출처, 연율화 √M | 부록 2 용어사전에 정의만(1723행), 연율화 언급 없음 | 출처 표기 오류(경미). 연율화는 ASSUMPTION |
| 해외 등급 경계 | `8.0 ≤ A < 9.0` 등 | "경계 표기가 겹친다, 8.00 = A"(1083행) | A 하단은 원문 사례로 확정. S 9.0·B 7.5·C 7.0 포함 방향은 ASSUMPTION |
| 역발상 경계 | `≤ −0.15 → +0.30`, `< 0.10 → 0` 등 | "구간 경계의 중복 표기는 구현 전에 정해야"(1225행) | 프롬프트가 정한 방향은 ASSUMPTION |
| 섹터 ETF 유동성 | `turnover_ratio ≥ 1.20` | "최근 1~2주 평균이 20% 이상 증가"(404행) | 비교 기준 창(직전 1주? 4주?)이 원문에도 없음. ASSUMPTION |
| DCF 이중계산 플래그 | "현금 이중 계산 차단 플래그" | 921행 | 플래그보다 입력 모드 하나로: `net_debt` 입력이면 NOA에서 현금 제외, `gross_debt`면 포함 |
| 자사주 소각 | `already_excluded_treasury_retired` 제외 | 1889행 | 1차 §3 권고대로 `r = 1 − WASO_t / WASO_{t−4}`면 이 플래그가 필요 없고 신주 발행 희석도 자동 반영. "신규 취득만" 방식은 희석을 놓침 |

### 3-4. 원문에 산식이 없는데 프롬프트가 만든 것 (ASSUMPTION 표시 필수)

| 항목 | 원문 | 프롬프트 |

| 생애주기 4단계 분류기 | 정성 표(328~343행). "상위권·약세"의 임계값 없음 | 임계값 없이 함수 요구 → 코덱스가 임의로 정함 |
| 시장 환경 보조 3지표 | 설명만(347행) | "표준편차/사분위 범위", "B/P 격차" 산식 |
| 2×2 교차검증 | "강함/약함" 수치 없음. 사례는 COMP 80+ & F 3~4(699~757행) | 임계값 미정 |

| 해외 Q·M·V·G 총점 | "내부 산식 미공개, 총점 역산해 공식 확정 금지"(1162행) | 등급·비중만 정의 — OK. 테스트에서 "총점 계산"을 요구하지 말 것 |

| 포트폴리오 배분 범위 검증 | 60~70 / 10~20 / 10~20, "합을 100%에 맞춰야"(1522·1537행) | 합계 검증 OK. 금·가상자산은 원문도 미완결이므로 제외 |
| COMP 급락 비교 기간 | "명확히 정의되지 않음"(998행) | 1차와 같음. 기간 ASSUMPTION |

### 3-5. 매도 규칙 7종 — 1차 지적 그대로

- 동시 발동 시 우선순위 없음(예: −20% EMERGENCY와 F ≤ 2 REDUCE가 같은 주에). `EXIT > REDUCE > HOLD` 명시.
- 사건당 1회 상태(`last_reduce_reason`, `last_reduce_at`, `comp_below65_since`) 없음 → 매주 반복 축소.
- F 4→3 `CONDITIONAL_HOLD_CHECK`는 "어느 항목이 깨졌는지"를 입력으로 받아야 하므로 `F_core` 합계가 아니라 항목별 불리언 4개를 저장해야 한다.

### 3-6. 집중투자 기여도 테스트

프롬프트의 "+200% → 40~66.67%p, +220% → 44~73.33%p, 100종목 2/2.2%p"는 원문 대조표(2054행)와 일치한다. 다만 원문 입력문의 "33~66%"(1960행)는 이 계산과 맞지 않는다고 원문이 스스로 주석을 달았으므로(1961행), 테스트 기대값에 33~66%를 넣으면 안 된다.

1차 §5 조사 결과를 완전판 함수 목록에 대입했다.

| 구분 | 함수 | 상태 |
|---|---|---|

## 6. 완전판 프롬프트 맨 앞에 붙일 보정 블록

아래 블록을 완전판 프롬프트의 `[구현해야 할 전체 수식 및 규칙 명세]` 바로 앞에 넣고, 충돌하는 부분은 이 블록이 우선한다고 명시한다. 나머지 완전판 본문은 그대로 둬도 된다.

```text
====================================================================
[공통 보정 규칙 — 아래 명세와 충돌하면 이 블록이 우선한다]
====================================================================

      /Users/tr-oh/Documents/Codex/ai-stock-점검-20261105-주도주수식-완전판.md (2차)

0. 구조
- 한 파일이 아니라 세 모듈: leader_core.py(Tier 1: 백분위·COMP·F·매도·손익비·섹터 ETF),
  leader_valuation.py(Tier 2: 16지표 후행분·듀퐁·자본배분·자사주·DCF·멀티플·NAV),
  leader_macro_overseas.py(Tier 3: CAPM·집중투자·레버리지·생애주기·해외 배분·순유동성·금리곡선·확산·손실회복·샤프).
- 모든 상수·임계값·경계 방향에 SOURCE(원문 행 번호) 또는 ASSUMPTION(구현 가정) 태그. 한 곳(constants.py)에 모은다.
- 데이터 매핑표는 1차 보고서 §5를 그대로 쓴다. 로컬에 DART 재무제표·수정주가·수급 금액·업종코드는 없다. 다시 조사하지 말고,
  "지금 가능 / 수집 후 가능 / 소스 없음"으로만 분류해 보고한다.

1. 수치 안전 규칙(전 모듈)
- 성장률·변화율 분모는 abs(기준값). abs(기준값) < 매출의 1%(또는 0)면 None.
- ROE: 자본총계 <= 0이면 None 처리 후 백분위 0점.
- 백분위 N < 2이면 None. 이산값(F_core 등) 동점은 평균 순위.
- 손익비: upside >= max(0.21, 3 * L). float 등식(== 0.07) 금지. L은 진입 시 1개로 고정해 저장.
- bp 변환은 round((y10 - y2) * 100). int() 금지.
- 가격 계열은 수정주가만.

2. F-스코어
- 비금융 전 종목 공통 4항목 F_core ∈ {0..4}, 항목별 불리언 4개를 함께 저장.
- 소재 발생액(OP − CFO < 0)은 accrual_ok 플래그. F_core에 더하거나 /5 정규화하지 않는다.
- 등급·매도 판정은 F_core로. 소재는 강력매수·매수에 accrual_ok 추가(ASSUMPTION).
- 매출원가 없는 성격별 손익계산서 기업은 F_core None.

3. 매도 규칙
- 우선순위: EMERGENCY(−20%) > EXIT > REDUCE > CONDITIONAL_CHECK > HOLD. 동시 발동 시 상위 하나만 반환.
- 포지션 상태 last_reduce_reason / last_reduce_at / comp_below65_since. 같은 사유로 REDUCE 2회 금지(F는 공시 1건당, COMP는 65 하회 구간당).
- COMP 급락 비교 기간 1주(ASSUMPTION).

4. 자사주
- r = 1 − WASO_t / WASO_{t−4} (자기주식 제외 가중평균 유통주식수). 신규 취득·소각 구분 플래그 불필요. 기보유 자기주식 소각 테스트는 "r 변화 0"으로.

5. 금리곡선
- steep/flat은 Δspread = dy10 − dy2 부호, bull/bear는 (dy2 + dy10) 부호. 둘 다 0이면 unchanged. twist·평행 이동도 분류된다(명명은 ASSUMPTION).

6. 원문 산식이 없는 항목은 함수 시그니처와 ASSUMPTION 기본값만 두고 "원문 규칙"이라 쓰지 않는다:
   생애주기 임계값, 시장 환경 3지표, 2×2 교차 임계값(기본 COMP 80 / F 3), 섹터 ETF 거래대금 비교 창,
   역발상·해외 등급 경계 포함 방향, 등급 비중 합계 모드(normalize 기본), 현금흐름 비율의 OCF/FCF(OCF 기본), 샤프 연율화.
   해외 Q·M·V·G 총점 계산식은 만들지 않는다(원문 1162행).

7. 테스트 기대값 고정
- 순유동성: 6.738 − 0.9108 − 0.005 ≈ 5.822 → "약 5.83"은 RRP를 명시한 값으로 검산.
- 애플: 3.02 × 1.74 ≈ 5.25, 로그 비중 0.666/0.334. 원자료(370/1120, 260.9/150) 재계산과 동시에 맞추지 않는다.
- 집중투자: +200% → 40~66.67%p, +220% → 44~73.33%p. 원문 입력문의 33~66%는 기대값에 넣지 않는다.
- 재무 건전성은 equity / total_liabilities(부채총계).
```
